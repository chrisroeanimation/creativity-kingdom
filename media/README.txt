PROJECT PICTURES AND VIDEOS
===========================

Each project has its own folder. The website finds the files by their names,
so to change a picture or video, just replace the file (keep the name) and upload.

  Folder      Project
  clayjam     Clay Jam
  chaos       Chaos Castle
  makes       Marvellous Makes & Lab
  creature    Creature Box
  strike      Strike
  sky         Sky Kids Christmas
  weasels     Wattle Weasels
  reel        Showreel & credits
  about       About me & CV (pictures here replace the portrait in the panel)

Inside a folder:

  01.jpg, 02.jpg, 03.jpg ...  Pictures, shown in this order. Number them with two digits
                              and don't leave gaps: the site stops at the first missing number.
                              .jpg, .png or .webp all work. 01 is shown big; the rest in a grid.
                              The first picture is also the project's thumbnail in "All work".
  video.mp4                   Optional. Plays at the top of the panel, streamed (it starts
                              playing before it has finished downloading).
  poster.jpg                  Optional. The still shown on the video before it plays.
  captions.txt                Optional. One line per picture, in the same order, e.g.
                                Clay Jam | Art Director | The hand-made hills before scanning
                              Leave a line blank for a picture without a caption.

Sizes that keep the site quick:
  Pictures: about 1600 px wide, JPEG quality ~80 (usually 200-500 KB each).
  Videos:   1080p (or 720p), H.264 MP4, "Web optimized / fast start" ticked,
            ideally under 50 MB each. GitHub refuses any single file over 100 MB.
            HandBrake preset "Fast 1080p30" with "Web Optimized" ticked does this.
